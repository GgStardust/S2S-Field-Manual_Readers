# Orb Images Required

This folder needs to contain all 13 Orb symbol images for the web book to display correctly.

## Required Files

Please add these 13 image files to this folder:

1. `orb_01_origin_intelligence.png` (or .jpg)
2. `orb_02_resonance_mechanics.png`
3. `orb_03_photonic_intelligence.png`
4. `orb_04_harmonic_architectures.png`
5. `orb_05_temporal_sovereignty.png`
6. `orb_06_starline_memory.png`
7. `orb_07_alchemical_current.png`
8. `orb_08_quantum_intuition.png`
9. `orb_09_temporal_fluidity.png`
10. `orb_10_ancestral_repatterning.png`
11. `orb_11_radiant_transparency.png`
12. `orb_12_sovereign_field.png`
13. `orb_13_bridging_intelligence.png` (also used as cover art)

## Image Specifications

- **Format**: PNG (preferred for transparency) or JPG
- **Resolution**: 300 DPI for print quality, 150 DPI minimum for web
- **Size**: 2-3 inches wide = 600-900 pixels at 300 DPI
- **Background**: Transparent (PNG) or white

## Where Images Appear

- **Title Page**: Orb 13 (cover art)
- **Each Chapter Opening**: Corresponding Orb (1-13)
- **Appendix A**: All 13 Orbs

Once you add the images, they will automatically appear in the web book!
